# 静态网站的内容组织

静态网站不代表内容必须是静态的。文章源文件保持简单，分类、导航、搜索和页面则在发布时自动生成。

## 内容与呈现分离

文章使用 Markdown 保存，主题集中控制颜色、字体和布局。因此更换主题不会修改文章，也不会改变文章地址。

```text
Markdown 内容 → MkDocs 构建 → HTML 静态页面 → GitHub Pages
```

## 两类内容

=== "文章"

    有明确发布日期，按时间归档，适合完整表达一个阶段的思考。

=== "知识页"

    位于稳定主题中，可以长期修订，适合形成可查询的参考资料。
