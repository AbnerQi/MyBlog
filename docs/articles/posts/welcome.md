# 从这里开始

这是“留白”的第一篇文章。

这个站点同时有两种阅读方式：文章保留时间顺序，适合了解最近在思考什么；知识库按照主题组织，适合带着问题查找。如果一篇文章值得长期维护，它也可以在知识库中获得一个稳定的位置。

<!-- more -->

## 内容如何生长

每篇文章都可以设置分类与多个标签。分类表达文章属于哪个较大的领域，标签负责建立更细、更灵活的关联。

!!! note "写作约定"

    一篇文章只保留一个源文件。归档、分类和标签页面都由站点自动生成，不需要重复整理内容。

以后只需要在 `docs/articles/posts` 中新建 Markdown 文件，就可以继续写作。
